# Saanvi Laboratories website

Phase 1 static website built with semantic HTML, CSS, and vanilla JavaScript. No build step is required. Serve this directory from a static host that supports clean URLs and routes missing paths to `404.html`.

## Local preview

Run any static file server from this directory, for example `npx serve .` (Node.js required), then open the local URL it prints. The site uses root-relative routes, so deploy it at the domain root.

## Before launch

- Replace `https://TODO-domain.example` in canonical tags, `robots.txt`, and `sitemap.xml` with the verified production domain.
- Confirm company statements, specialty support, service scope, legal content, contact details, and business hours with Saanvi Laboratories.
- Connect both enquiry forms to an approved backend or form-processing endpoint, with server-side validation and spam controls. The current form intentionally reports that no enquiry was sent; it does not redirect to the thank-you page.
- Add verified phone/WhatsApp details, office address/map, approved social links, and approved Open Graph image if available.
- Configure static hosting to serve folder `index.html` for clean routes and use `404.html` for unknown routes.

## Routes

Home, About (including Vision and Mission, Core Values, Infrastructure), Services overview and six service pages, Specialties, Why Outsource, Our Commitment, FAQs, Contact, Consultation, Privacy Policy, Terms, Thank You, and 404.

No testimonials, numerical performance claims, certifications, client details, or unverified company history are included.
